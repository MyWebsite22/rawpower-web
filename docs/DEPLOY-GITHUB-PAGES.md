# Publicación en GitHub Pages

## Paso 1
Sube todos los archivos del proyecto a la raíz del repositorio.

## Paso 2
GitHub → Settings → Pages.

## Paso 3
Selecciona:
- Deploy from a branch
- `main`
- `/ (root)`

## Paso 4
Guarda.

## Paso 5
Activa HTTPS y, si quieres, un dominio personalizado.

## Importante
GitHub Pages no ejecuta:
- Node.js
- Express
- claves privadas
- bases de datos

Por eso esta edición está pensada como frontend/PWA. La IA privada debe conectarse a un endpoint seguro externo.
